        Connect a PWA

        Load the SDK from kimo and use the key of the app:

        import { Kimo } from '/sdk/kimo.js';
import '/sdk/kimo-terminal.js';

const kimo = new Kimo({ url: '', token: 'kimo_…' });
kimo.subscribe(({ sessions }) => render(sessions));
await kimo.pause(id);  await kimo.send(id, 'run the tests');

        Embed a terminal: <kimo-terminal session="…"> with .kimo = kimo. Full API in the README.
